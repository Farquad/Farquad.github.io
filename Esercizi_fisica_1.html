Esercizi di Fisica

  1. Utilizzando l'applicazione presente in questo link indica almeno un oggetto (in lingua italiana) che abbia una misura lineare vicina a
    1. 1 Megametro
    2. 1 Gigametro
    3. 1 kilometro
    4. 1 millimetro
    5. 1 micrometro
    6. 1 nanometro
    riportando le dimensioni di ciascuno di tali oggetti (fornite dall'applicazione clickando su di essi) in notazione scientifica.
  2. Determina il risultato delle seguenti espressioni:
    1. $$\frac{10^{30} \cdot 10^{-7}}{10^{-12}}\cdot 10^{34}$$
    2. $$\frac{10^9 \cdot 10^{-100}}{{(10^{7})}^7}\cdot 10^{58}$$

  3. Trasforma in notazione scientifica i seguenti numeri:
    1. $124'300'000'000'000$
    2. $10$
    3. $0,000 \ 000 \ 000 \ 000 \ 000 \ 012$
    4. $348 \times 10^{1000}$

  4. Riempi gli spazi individuando il numero mancante in notazione scientifica:
    1. $0,003 \ \mathrm{m} = \ldots \ \mathrm{km}$
    2. $197 \ \mathrm{km} = \ldots \ \mathrm{m}$
    3. $2000 \ \mathrm{cm} = \ldots \ \mathrm{km}$
    4. $1 \ \mathrm{\mu m} = \ldots \ \mathrm{Gm}$
    5. $10^{-20} \ \mathrm{km} = \ldots \ \mathrm{nm}$

  5. Riempi gli spazi individuando il numero mancante in notazione scientifica:
    1. $2 \times 10^{12} \ \mathrm{cm} = \ldots \ \mathrm{km}$
    2. $10^{-10} \ \mathrm{km} = \ldots \ \mathrm{mm}$
    3. $10^{50} \ \mathrm{\mu m} = \ldots \ \mathrm{Gm}$

  6. Determina il risultato delle seguenti espressioni:
    1. $$\frac{10^{10} \cdot 10^{-20}}{10^{-30}}\cdot 10^{-1}$$
    2. $$\frac{10^{-1} \cdot 10^{-99}}{{(10^{50})}^{-2}}\cdot ({10^{-2}})^{-3}$$

  7. Riempi gli spazi individuando il numero mancante in notazione scientifica:
    1. $0,00003 \ \mathrm{m^2} = \ldots \ \mathrm{km^2}$
    2. $197 \ 000 \ \mathrm{km^2} = \ldots \ \mathrm{m^2}$
    3. $2 \ \mathrm{cm^2} = \ldots \ \mathrm{km^2}$
    4. $1 \ \mathrm{\mu m^2} = \ldots \ \mathrm{Gm^2}$
    5. $10^{-10} \ \mathrm{km^2} = \ldots \ \mathrm{nm^2}$
  8. Riempi gli spazi individuando il numero mancante in notazione scientifica:
    1. $0,000 \ 005 \ \mathrm{m^3} = \ldots \ \mathrm{cm^3}$
    2. $20 \ 000 \ 000 \mathrm{km^3} = \ldots \ \mathrm{m^3}$
    3. $100 \ \mathrm{mm^3} = \ldots \ \mathrm{dm^3}$
    4. $1 \ \mathrm{\mu m^3} = \ldots \ \mathrm{Gm^3}$
    5. $10^{-5} \ \mathrm{km^3} = \ldots \ \mathrm{nm^3}$
  9. Riempi gli spazi individuando il numero mancante in notazione scientifica:
    1. $1 \ \mathrm{s} = \ldots \ \mathrm{h}$
    2. $1 \ \mathrm{settimana} = \ldots \ \mathrm{s}$
    3. $100 \ \mathrm{s} = \ldots \ \mathrm{min}$
    4. $10^{10} \ \mathrm{\mu s} = \ldots \ \mathrm{h}$
    5. $1 \ \mathrm{min} = \ldots \ \mathrm{ns}$
  10. Riempi gli spazi individuando il numero mancante in notazione scientifica:
    1. $0,000 \ 005 \ \mathrm{m^2} = \ldots \ \mathrm{cm^2}$
    2. $20 \ 000 \ 000 \ \mathrm{km^2} = \ldots \ \mathrm{m^2}$

    4. $10^{10} \ \mathrm{\mu m^3} = \ldots \ \mathrm{Mm^3}$
